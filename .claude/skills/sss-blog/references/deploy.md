# デプロイ・Git操作

## 概要
SSS Blogの変更をGitにコミット・プッシュする手順です。

## 実行手順

### 1. 変更の確認
```bash
git status
```

### 2. リモートからプル
```bash
git pull
```

### 3. 変更をステージング
```bash
git add -A
```

### 4. コミット
```bash
git commit -m "{type}: {message}"
```

**コミットタイプ**:
| タイプ | 用途 |
|--------|------|
| `feat:` | 新機能、新規記事 |
| `fix:` | バグ修正 |
| `docs:` | ドキュメント更新 |
| `style:` | スタイル変更 |
| `refactor:` | リファクタリング |

**例**:
```bash
git commit -m "feat: 新規記事追加 - STM32入門"
git commit -m "fix: モバイルレイアウトの修正"
```

### 5. プッシュ
```bash
git push
```

## 注意事項
- プッシュ前に必ず `git pull` を実行
- コンフリクトが発生した場合は解決方法を提案
- 大きな変更の場合は事前にビルドテストを推奨
